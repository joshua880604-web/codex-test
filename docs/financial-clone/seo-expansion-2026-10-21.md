# 全站搜索意图与长尾布局 — 2026-10-21

当前为纯静态版本，不接外部 API。此次优化不改变数学模型、不建立重复落地页、不添加广告或分析请求。

## 变化

- 原先只有 8 个重点工具的 12 个搜索任务有专门用途入口。新增 67 个工具的用途入口，现全部 75 个实际计算器共 79 个搜索任务均有可见标题、说明和指向真实模式的链接。
- 67 个新词来自实际输入、计算模式和功能边界的人工整理，全部标为 editorial candidate；未查询或声称它们具有特定搜索量、自然排名难度或转化率。用户此前提供的美国/全球数据保留原始出处和不明确行限制。
- 各计算器补齐独立页面标题；长尾描述与所支持模式相符。未将多个工具的同一主词重复归属到不同新页面。修正 401(k) 用途说明：新增员工缴款不含起始余额，起始余额另列。
- 全部 75 个计算器具有相关任务的工具内链。原有单独策划的关联保留，缺失页面按贷款、房产、税薪、养老、投资和日常用途补齐。
- 添加 6 条与本地模型相关的问答，说明立即退休缺口、401(k) 新缴款口径、额外房贷与税险、额外还款发生时点、离线汇率、工资税预扣限制。
- 算例与模型假设增加稳定片段链接，WebPage 结构化数据指向对应正文；WebApplication 列出实际任务。无虚构作者、审核者、评级、引用或 FAQ 富结果保证。

## 验证与限制

- npm test：476 项通过，含全站任务模式有效性、关键词归属唯一性、指南算例及静态无 API 检查。
- npm run build：静态构建通过。
- node --import tsx scripts/check-page-intents.mts：75 页 / 79 个任务通过；检查静态 HTML 可见标题、模式链接、独立标题、相关内链和引用片段。
- python scripts/check-seo-build.py：80 页静态标题、说明、H1、结构化数据和预览 noindex 规则通过。
- 浏览器 115 项检查通过，包含全部 107 个可复算算例链接及响应式抽查，记录在 evidence/browser-seo-qa.json。该结果只验证本地内容/计算交互，不是搜索引擎收录、排名或 AI 引用效果。

默认预览依旧 noindex；正式收录需要实际域名、SITE_URL 与 SITE_INDEXABLE=true 后重建。尚未配置真实生产域名，也没有 Search Console 的收录/曝光/点击或 AI 平台引用数据。新增候选词应在后续关键词工具与真实曝光数据中进一步筛选，而不是宣称全站 SEO/GEO 已优秀。
