# 可复算链接、结果摘要与本地 PNG — 2026-10-21

按用户要求先完善结果分享，再提供图片导出。数学模型、正式域名、收录开关和广告接入不在本轮改动范围。仍为纯静态，无外部 API 或新依赖。

## 用户流程

结果说明与明细表之后提供紧凑分享区，不再重复展示结果摘要。默认显示复制摘要和下载图片；链接操作放在用户主动展开的区域中，收起时取消包含输入的选择。链接默认只复制工具页地址。用户主动勾选 Include current inputs in the link 才将当前模式的输入写入链接；未声明的字段和旧 verified_rate 不会带入。金额可能敏感，摘要和图片按钮旁明确说明。localhost 预览提示链接仅适用于本机。

- Copy link：复制工具页，或用户选择后的可复算链接。
- Share link：优先使用浏览器原生分享；不支持时回退到复制。取消分享不会当作成功发送。
- Copy result summary：最多五个选定指标，保留金额/百分比/日期和币种格式、模型说明以及所选链接。税年和换算方向进入摘要标题上下文。
- Download result PNG：本地 Canvas 生成固定 1200 × 1680px（5:7）竖版 PNG，包含标题、模式、选定结果、简短结果解读/模型说明、生成日期和工具地址。没有输入明细或表格，不截图广告/页面 DOM；金额仍在图片中。图像模块按点击延迟加载，不请求外部字体、图片或生成服务。
- 原有 Print、CSV 和年度/逐期表保持可用。打印时隐藏分享操作区。

剪贴板被拒绝或不可用时提供可选择的只读文本框，不虚报复制成功。输入变化时结果和分享区一并移除，重新计算后默认重新关闭输入分享。

## 分享协议与兼容

新链接使用 `#calc=share_version=1&mode=...`，已知模式字段全部显式序列化，包含空白值、零、多行文本。输入位于地址片段，正常请求不会把片段发给静态服务器；它不是加密，收件人可以读取，也可能保留在浏览器历史中。旧 query 参数链接仍可用，其隐私范围不同，隐私页已说明。

接收页按输入重新计算，不传固定输出伪装结果，模型/数据更新可能改变未来结果。支持 hashchange 和前进后退；普通指南锚点不会重置编辑中的值。未知模式或版本显示错误，不静默显示默认结果。旧 VAT net/gross/tax/rate 模式映射到 any-two，旧 currency live 模式映射到注明日期的离线快照。

链接超过 20,000 字符时给出说明并建议只分享工具页；未使用第三方短链或云端存储。

## 2026-10-22 — 手机阅读的 5:7 结果卡

导出固定为 **1200 × 1680px** 的高清竖版。主数值最大 84px、辅助数值 48px；长金额在 40px 下限内适配再换行，保持原有显示精度与所有数字。说明文字为 30–34px，标题 52px；网站品牌 **calculatorfree.io** 以 64px 粗体固定在页脚，带无输入参数的实际工具地址。
