# Tax Equivalent Yield Calculator

ID tax-equivalent-yield; mode compare. Approved independent new tool, reviewed2026-10-27. Canonical https://www.calculatorfree.io/tax-equivalent-yield-calculator; static file /tax-equivalent-yield-calculator.html.

Defaults: exempt annual yield4%, taxable comparison5%, federal24%, state/local/surtax0%, municipal state/local Exempt, amount$10,000. Each tax component0..99%; combined rates must be<100%. Amount0..1e12, nonnegative entered yields0..99%. No automatic tax bracket or exemption determination.

Formula: TEY=yE(1−tE)/(1−tT); after-tax yield=y(1−t). Taxable taxes add entered federal/state/local/optional investment-income rates. Exempt option federally exempt, with selected full state/local applicability. Components assumed non-overlapping and no deduction interactions. Income=principal×annual yield, no compounding. Hypothetical rate sensitivity table holds exempt taxation fixed. Positive after-tax advantage favors exempt; negative favors taxable. No equivalence of credit, duration, liquidity or investment risk. State-taxed muni versus state-exempt Treasury needs independent per-investment state rates and is outside this form. AMT, fund allocation, capital gain, NIIT threshold and retirement-account models excluded.

Standard Calculate/Reset, unit labels, validation, all metrics, sensitivity CSV, rich PNG with opt-in inputs and free badge, print/share. No unsupported time curve. Sources and independent examples are in investment-decisions-guides.json and investment-decisions-2026-10-27.md. Tests cover equalized net income, state/local exemption, surtax, near100% rates,zero inputs,invalid values,search,lazy andPNG data.22 shared browser checks include desktop/mobile and exports; native Safari/reference form parity unverified.
