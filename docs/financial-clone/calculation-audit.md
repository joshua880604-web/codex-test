# 计算准确性与原站一致性审计 — 2026-10-19

## 结论

当前版本不能认定为 Calculator.net 金融区的完整等价实现。本轮重新读取全部 71 个目录条目的可访问文本（其中 Real Estate 是工具目录，其余 70 个是计算页），复查关键共用公式、退休与税务规则，并确认及修复以下 8 类问题。取得页面文字、运行默认案例、浏览器提交成功，都不能替代同一输入下的原站结果比对。

审计对象是 `/workspace/financial-calculators` 的当前代码和 GitHub financial-calculators 分支，不是用户电脑中此前下载的旧 ZIP；旧版本需要更新后才能获得修复。

## 已通过的对照与独立检查

- 原站文章的 25 个命名案例测试通过，涉及 IRR、复利频率转换、终值、单利、折扣、VAT、佣金、利润率、工资、HELOC 和 DTI。这是案例层面的证据，不意味着这些工具全部模式原站对齐。
- 原站可见 Annuity 表格案例：起始 20000、年初加 10000、无月缴、年收益 6%、10 年；原站年末 175533.38、收益 55533.38，本地相符。参数含义可由展示的逐期表与结果确认，不属于本轮实时提交表单案例。
- 120 组独立贷款/复利迭代验证：本金守恒、末期余额、闭式结果与逐期累积一致；包括零利率。
- 工资频率、车辆税基、IRS 联合寿命表、税档、分期额外还款、折旧与债券等已有回归继续通过。
- 另对 IRS Schedule A 的 MFS SALT 计算顺序和 Schedule 1-A 的小费/加班 phaseout 取整方式核验；现有实现相符，未因直觉猜测而改动。
- 全部测试合计 247 项，其中默认模式 smoke 测试只证明结果有限/可运行；不能当作 247 个独立原站对照。

## 与原站仍存在的功能/规则差距

| 范围 | 当前差距 | 审计判断 |
| --- | --- | --- |
| 401(k) 主投影 | 本地只投影到退休；原站说明还包含退休后分配。Life expectancy 不参与本地主投影。未来贡献上限固定使用 2026 值，未推演未来法律及综合员工/雇主上限。 | 未完整对齐，不能称为原站等价。 |
| Maximize Employer Match | 原站描述避免过早缴满上限的缴款比例窗口；本地只是两档年度配比金额，未模拟逐次发薪与全年配比损失。 | 功能不足。 |
| 401(k) Early Withdrawal | 原站逐项选择离职年龄、就业、残疾及其他豁免；本地将资格折叠为手动豁免开关。 | 某些已选资格下公式可正确，但交互/资格推断不等价。 |
| 税务/Take-home/Marriage Tax | 州税为手动比例或未完整计算；paycheck 使用年度税额分摊而非完整 Publication 15-T 预扣工作表；QBI/AMT、抵免资格等仍简化；不含完整夫妻分别申报优化。 | 输出不能当作完整税表或原站完全一致。 |
| 原站 Retirement 的输入 | 首个模式的原站收入/储蓄选择项，以及月提款模式的独立年度缴款，尚未全部映射到本地字段。 | 输入覆盖有差距；本轮公式修复不消除这些缺项。 |
| 房产/租买/贷款保险 | 租买税收模型简化；精确 PMI/MIP、费用和日数/分币舍入等仍缺逐项原站对照。 | 需要更完整的参数化证据。 |
| 汽车税 | 仅 8 州有已研究的合资格 dealer 税基处理；地方税上限和其余州、船舶特殊规则不全。 | 不能声称全州自动税务引擎。 |
| 债券/折旧 | 规则明确的常规模式可测；原站具体日数变体、折旧 convention 下拉选项等仍未提取完整。 | 部分未验证。 |
| 汇率 | 手动和带日期快照可用；实时行情须由运行环境实际访问提供方验证。 | 不可将静态回退视为实时价格。 |
| 全站 | 原站同输入提交和精确默认选项不可用；自定义请求失败；页面/模式数完整不代表所有分支公式一致。 | 不能给出全站一致率或“零错误”保证。 |

用户要求把 Current 401(k) balance 加入员工缴款汇总，是有意定制。当前标签明确为 Employee contributions + current balance，起始余额只加一次，不更改逐年 Employee 列，也不对投影余额重复加本金。这个口径不能在未查看原站对应结果定义时宣称相同。
